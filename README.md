## 📌 Project Details

### 1. Hangman Game

A terminal-based implementation of the classic **Hangman word-guessing game**.

**Features:**

* Randomly selects a technology-related word.
* Displays the hidden word using `_`.
* Tracks incorrect guesses.
* Allows up to 6 incorrect attempts.
* Validates repeated and incorrect guesses.

**Skills demonstrated:** Python fundamentals, loops, conditional logic, strings, lists, and randomization.

---

### 2. Stock Portfolio Tracker

A command-line application that calculates the total investment value of a stock portfolio using predefined stock prices.

**Features:**

* Accepts stock symbols and quantities from the user.
* Uses a dictionary to map stocks to prices.
* Prevents duplicate stock entries.
* Calculates individual investment values.
* Displays the overall portfolio value.

**Skills demonstrated:** Dictionaries, input validation, calculations, loops, and data handling.

> **Note:** The application uses predefined stock prices for demonstration purposes; it does not fetch live market prices.

---

### 3. Automated Image File Organizer

A Python automation script designed to organize `.jpg` files within a directory.

**Features:**

* Scans a specified source folder.
* Identifies `.jpg` image files.
* Automatically creates the destination folder when required.
* Moves matching files using Python's `shutil` module.
* Handles missing folders and common file-operation errors.

**Skills demonstrated:** File system automation, `os`, `shutil`, directory management, and exception handling.

---

### 4. Basic Rule-Based Chatbot

A simple console chatbot that responds to predefined user messages using rule-based logic.

**Features:**

* Handles common greetings and questions.
* Uses case-insensitive input processing.
* Continues the conversation until the user enters `bye`.
* Provides a fallback response for unknown inputs.

**Skills demonstrated:** Functions, loops, conditional statements, string processing, and user input handling.
